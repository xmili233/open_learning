# UI 变更方案：K12 共享教学纸面

> Status: approved
>
> Owner: Open Learning
>
> Approved by: project owner
>
> Approved at: 2026-09-02

## 1. 决策摘要

- 变更：把正式教学画板从卡片关系图改为一张可持续书写的极简纸面。
- 用户：使用 Codex Voice 完成初中数学学习的学生。
- 主要用户任务：在同一张纸上看见题目、Codex 的最小提示与自己的作答，并能随时打断或指向其中一行。
- 期望结果：学生一眼看见当前焦点，能区分自己与 Codex 的内容，并由自己完成题目的关键步骤。
- 不做什么：通用白板、自由手绘识别、逐笔 AI 动画、卡片布局、连线、装饰性纸张纹理。
- 更简单的方案及未采用原因：保留卡片列表只改颜色无法形成“共同在一张纸上解题”的产品心智。

## 2. 用户意图

| 意图 | 用户 | 场景 | 占比 | 成功标准 |
| --- | --- | --- | ---: | --- |
| 跟随当前讲解 | 学生 | Codex Voice 正在解释 | 60% | 一眼找到页边焦点箭头与当前行 |
| 在纸上作答 | 学生 | Codex 提出可判定问题 | 25% | 键盘提交后出现非颜色依赖的结果 |
| 指向并打断 | 学生 | 对某行有疑问 | 15% | 点击一行或空白后 Codex 可通过 read 获得事件 |

## 3. 信息架构与布局

- 进入方式：Codex 通过 CLI 打开或更新教学会话时，桌面 app 显示当前纸面。
- 视觉层级：当前焦点 > 学生题目/作答 > Codex 脚手架 > 已折叠步骤。
- 主要操作：在 question 下划线上输入并提交答案。
- 次要操作：点击一行选择；点击空白打断并清除选择。
- 响应式变化：窄窗口保持单列纸面；内容纵向滚动，不产生水平滚动。
- 溢出和长文案处理：自然换行；公式区域允许局部横向滚动。

## 4. 状态

- 正常：米白纸面按写入顺序展示内容。
- Loading：沿用现有 Skeleton。
- Empty：沿用现有 Empty，提示去 Codex Voice 开始学习。
- Disabled：答案为空时提交按钮禁用。
- Success：答案正确时显示手画对勾与可访问文本。
- Error 与恢复：答案错误时保留输入，由 Codex 依据回读事件给下一步提示。
- Offline / unavailable：沿用现有画板不可用错误与重试。
- Cancelled：学生事件让版本递增，过期 patch 被拒；现有纸面不回滚。
- Destructive：不提供用户侧破坏操作；AI clear 仅移除 AI 对象。

## 5. 组件和 Token

- 复用的 shadcn 组件：Button、Empty、Skeleton、Dialog、Sonner、Tooltip。
- 新增的 shadcn 组件：无。
- 自定义组件及现有 primitive 不足的原因：纸面内容、墨迹、马克笔与页边箭头属于 learning-content renderer，不是产品 chrome；shadcn 没有对应教学原语。
- 颜色 token：新增 `paper`、`ink-student`、`ink-ai`、`marker`；不在组件内写原始颜色。
- 字体 token：新增平台手写字体栈，只用于教学纸面；产品 UI 继续用系统 sans。
- 间距、圆角、尺寸、阴影和动效 token：4px 网格；纸面无卡片圆角、阴影或装饰纹理；仅用 150ms 透明度变化，reduced-motion 下关闭。

## 6. 操作后果

| 操作 | 可撤销 | 外部或重要影响 | 自动 / 直接操作 / 明确确认 | 恢复方式 |
| --- | --- | --- | --- | --- |
| 提交答案 | 否 | 生成学生事件并使版本递增 | 直接操作 | 继续修改后再次提交 |
| 选择一行 | 是 | 生成选择事件并使版本递增 | 直接操作 | 点击空白 |
| 点击空白 | 是 | 生成打断事件并清空选择 | 直接操作 | 再次选择一行 |

## 8. 可访问性与国际化

- 语义结构和可访问名称：纸面使用 main/section/form；每行可选择对象有 button 语义；对勾有文本说明。
- 键盘顺序和 Focus：按纸面顺序进入可选行、输入框、提交按钮；可见 focus ring 沿用全局规范。
- 非颜色状态提示：owner、焦点和判定均有图形或文字，不只靠墨色。
- Reduced motion：透明度与揭示动画关闭。
- 200% 文字缩放：单列自然换行，控制不覆盖内容。
- 英文和中文长度风险：纸面自然换行；按钮使用完整双语词组。
